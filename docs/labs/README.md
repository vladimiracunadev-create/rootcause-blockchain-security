# Laboratorios de Blockchain Forensics

Ocho prácticas reproducibles sobre datos ficticios. Todas trabajan en modo
**READ ONLY**, usan `examples/forensics/investigation.json` y distinguen hechos,
registros aportados, inferencias e hipótesis. Ejecuta primero `node src/cli.js help`.

| Lab | Resultado verificable |
| --- | --- |
| [1](LAB-01.md) | Validación normalizada de una transacción |
| [2](LAB-02.md) | Perfil de actividad de una dirección |
| [3](LAB-03.md) | Reconciliación con ledger CSV |
| [4](LAB-04.md) | Salida on-chain sin asiento interno |
| [5](LAB-05.md) | Grafo multiwallet acotado |
| [6](LAB-06.md) | Timeline de cuatro relojes |
| [7](LAB-07.md) | Informe de evidencia con hashes |
| [8](LAB-08.md) | Integración con RootCause Server |
